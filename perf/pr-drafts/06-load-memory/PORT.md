Layout facts on origin/master (checked with git show; nothing built):
* Two engines, each with its own `Impl` (weights loaded in the `Impl` constructor, `dalloc` with `cudaMalloc` + 16 B, `parallel_rows` spawning `hardware_concurrency()` threads per call: l.2134 in `qwen38_mk.cu`, l.2275 in `qwen38_mixed.cu`; embedding in mapped pinned memory since 5667332). Shared: `prefill.cuh`, `qwen38_mk.h`, `capi.cpp`, `main.cu`, `server/mk_server.py`, `logit_stats.h`. * Upstream bench.py still has the `IDS:(.*)` regex (`bench/bench.py` l.95): the `--dump` fix applies as is.

## Suggested order
1. Standalone, no dependency on PRs 1-5: items 7, 8, 9, 10, 11, 12, and loader step 1 (item 1 without the wv part). Items 8 and 9 and 12 are small enough to go first.
2. After PR 2 / PR 1: items 5 (native types), 2 (device wv), the wv part of item 1.
3. After PR 4 / PR 5: item 4 (state files).
4. Item 6 (penalties): after #21 is reconciled with PR 1; needs a fresh exactness argument and the chi-square test.

Item 3 (`--batch`) has no dependency and is cheap; it makes the porting gates of all other PRs faster (tinv in one process), so it is worth doing first.
